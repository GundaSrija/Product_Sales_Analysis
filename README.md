# Product Sales Analysis With Python

## Overview

This project focuses on analyzing product sales data using Python to uncover business insights, trends, and customer purchasing patterns. The analysis includes data cleaning, preprocessing, exploratory data analysis (EDA), and visualization techniques.

The project demonstrates practical usage of Python libraries for handling real-world sales datasets and generating meaningful insights for decision-making.

---

## Features

* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* Sales Trend Analysis
* Product-wise Performance Analysis
* Monthly Revenue Analysis
* Data Visualization using Charts and Graphs
* Insights and Business Recommendations

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Installation

### Clone the Repository

```bash
git clone https://github.com/GundaSrija/Product_Sales_Analysis.git
```

### Navigate to the Project Folder

```bash
cd Product_Sales_Analysis
```

### Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn
```

---

## Usage

1. Open Jupyter Notebook or VS Code.
2. Run the notebooks:

```bash
Product_Sales_Analysis.ipynb
```

or

```bash
Sales_Analysis.ipynb
```

3. Explore the visualizations and insights generated from the dataset.
